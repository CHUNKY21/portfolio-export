## 🎯 Key Principles

### 1. Three-Level Design System Hierarchy
- **Container:** Foundational design language
- **AI Portfolio:** Shared patterns for 5 AI projects (independent)
- **Projects:** Unique identities (completely independent)

### 2. Centralized Content
- **Briefs** live in one place (`briefs/`)
- **Web pages** live in one place (`site/`)
- **Projects reference them** rather than duplicating

### 3. Independent Design Systems
- Each level has its own design system
- Levels don't inherit from each other
- But all use Poppins typography (unified baseline)

### 4. Clear Navigation
- Every README.md has breadcrumb navigation
- Every CLAUDE.md has project-specific guidance
- Every folder is self-documenting
